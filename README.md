# Crystal Maiden

Crystal Maiden is a 2D top-down game developed in Unity using C# as part of a university Games Development project at the University of Limerick.

The game was developed collaboratively by a team of seven students and involved designing, programming and integrating different gameplay systems within a project deadline.

## My Contributions

My individual contributions to the project included:

- Developing and implementing gameplay features using C#
- Implementing player movement and directional attack mechanics
- Developing enemy movement, combat and player detection systems
- Implementing player and enemy health systems
- Working with Unity's animation system to support directional movement and combat
- Implementing audio and music functionality
- Using Git and GitHub for version control and team collaboration
- Helping organise project goals and track development progress with the team
